# MomBoard v0.2 — "From archive to advisor"

*Release definition. v0.1 (T01–T23, shipped) stores and tags conversations. v0.2 makes the repository talk back: it preps you, nags you, answers you with receipts, and trains you.*

## Theme

v0.1 answers "what did customers say?" v0.2 answers "what should I do next?" — before the call (briefs), during practice (simulator), after (hypotheses, decisions), and continuously (staleness, digest, chat).

## Build order

```
1. T34 inbox                     (keystone — every source lands here)
2. T27→T28 hypotheses            (the soul of v0.2)
3. T29→T30 contact memory        (read-models + drift)
4. T38 briefs                    (daily-use payoff; needs T29)
5. T24 Meet/Drive                (auto-ingestion once inbox exists)
6. T41 staleness → T31 digest    (staleness feeds the digest's new section)
7. T42 corpus chat               (two-stage retrieval; also lands `ask_corpus`…)
8. T25 MCP server                (…which ships as an MCP tool here)
9. T44 quote cards               (independent; slot anywhere as a palate cleanser)
```

Rationale: 1–4 make the tool indispensable to its owner before any automation; 5 removes the copy-paste toll; 6–8 make the corpus interrogate-able from anywhere (including Claude); 9 is the share loop.

## Definition of done (release gate)

- All tasks green under the `tasks/README.md` conventions (LLM faked in tests, both DB dialects in CI).
- The 8 fixtures flow end-to-end: Drive-style doc → inbox → import → tagged → hypothesis evidence → appears in a brief → citable in chat → exportable as a card.
- Wiki updated: [[Task Plan]] moves shipped rows to Done; [[Roadmap]] horizons re-cut for v0.3.
- Scoreboard on the website updated (commitments, not compliments).

## Risks / watch-list

- **Meet transcript Doc format drift** (Google changes the layout): keep the parser fixture-pinned, fail to inbox with `parse_error` status rather than dropping.
- **Brief/chat quality on small corpora**: both must degrade honestly (tested) — empty sections and gap-answers, never padding.
- **Feature sprawl**: v0.2 adds 7 surfaces; the Library/Conversation core flow must not gain a single extra required click. Anything that does gets cut.
