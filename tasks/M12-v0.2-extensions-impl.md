| Method | Path | Auth | Description |
|--------|------|------|-------------|
| GET | `/api/inbox` | session | List items, filter by status/source |

- `DuplicateSourceRefError` — raised on source_ref collision

## T24: Google Drive / Meet Polling

### Config (`app/config.py`)

- `gdrive_folder_id: str` — Drive folder to poll
- `gdrive_service_account_json: str` — path to SA key file
- `gdrive_poll_interval_minutes: int = 30`

### Service Layer (`app/services/gmeet.py`)

- `parse_meet_doc(content: str) -> tuple[str, str | None]` — parse Meet transcript Doc
- `poll_drive_for_transcripts(db, settings) -> list[dict]`
  - Authenticates via service account JWT
  - Lists all pages (loops on `nextPageToken`)
  - Exports each Doc as plaintext
  - Dedupes on `source_ref = f"gdrive:{doc_id}"`
  - Parse errors stored with `status='parse_error'`

### Worker Handler (`app/worker.py::handle_gmeet_poll`)

- Calls `poll_drive_for_transcripts`
- Self-reschedules next poll (idempotent — no duplicate queued jobs)

## T25: MCP Server (Model Context Protocol)

### Transport Architecture

- **stdio**: `python -m app.mcp_server` — uses `mcp.server.stdio`
- **Streamable HTTP**: `POST /mcp` on FastAPI app — custom JSON-RPC handler with auth

### Auth Boundary

- HTTP: requires a valid **signed session token** — either as `Authorization: Bearer <token>`
  or as a `session` cookie. The token must be cryptographically verified (signature + expiry)
  using the app's `session_secret`, and the referenced user must exist in the database.
  Presence-only credentials (e.g., `Bearer garbage`) are rejected with 401.
- Unauthenticated / invalid / expired / nonexistent-user → 401 JSON-RPC error
- stdio: implicit trust (local process)

### 7 Tools (shared service layer)

| Tool | Required Params | Service |
|------|----------------|---------|
| search_conversations | q?, company?, limit? | SQLAlchemy query |
| get_conversation | id | db.get + utterances + highlights |
| get_highlights | tag?, status?, limit? | SQLAlchemy query |
| get_commitments | open_only?, limit? | Filter tag_key in (commitment, followup) |
| run_synthesis | filters | Create Analysis + enqueue Job |
| create_conversation | title, transcript | submit_to_inbox (dedupe) |
| ask_corpus | question, filters? | corpus_chat.ask_corpus |

### Schemas

All tools have `inputSchema` with `type: object`, `properties`, and `required` where applicable.
